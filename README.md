# Silent Partner Coding

Agent security and evidence provenance — whether a system can show *why* it trusted
something, not just that it did.

Most repositories here are experiments and reference implementations from that one line
of work. They are research code, not production tools.

## Start here

- **[Minority Prophet](https://github.com/Silentpartnercoding/minority-prophet)** — how copied or commonly controlled claims should affect an evidence assessment.
- **[Minority Prophet Border](https://github.com/Silentpartnercoding/minority-prophet-border)** — portable admission records binding identity, delegated authority, a proposed action, destination policy, and evidence.
- **[Minority Prophet Gate](https://github.com/Silentpartnercoding/minority-prophet-gate)** — a deterministic-policy-first decision ladder.
- **[Agent Ablation Harness](https://github.com/Silentpartnercoding/agent-ablation-harness)** — whether assistance given to an agent changes the judgment it produces, measured against a blind control arm.

Work in other people's projects: [merged pull requests](https://github.com/search?q=is%3Apr+author%3ASilentpartnercoding+is%3Amerged+-user%3ASilentpartnercoding&type=pullrequests).

Evidence assessment does not grant authority. A different name, key, service, or
verifier does not by itself establish independence.
