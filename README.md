# Silent Partner Coding

I build applied systems at the boundary of agent trust, automation, spatial computing, and production software.

## Selected work

### [Osmo Arcam](https://github.com/Silentpartnercoding/osmo-arcam)

An iPhone ARKit virtual camera and diagnostics tool with camera-path recording, portable take packages, live network streaming, Unreal Engine Sequencer import, coordinate-system conversion, and experimental Gaussian-splat tooling.

### [Nxtlinq Attest](https://github.com/Silentpartnercoding/nxtlinq-attest)

Active upstream work on cryptographic agent authorization and enforceable host integration. The current contribution focuses on placing verified policy decisions in the execution path so a denied operation is actually prevented—not merely observed.

## Current focus

- Verifiable authorization and receipts for coding and browser agents
- Human approval workflows for high-impact automated actions
- ARKit, RealityKit, Unreal Engine, and virtual-production interoperability
- Reliable automation around real products and operational constraints

I prefer narrow proofs that work, explicit trust boundaries, and documentation that distinguishes implemented behavior from future architecture.
